# Key4 · 四键小键盘设置工具

**[⬇ 下载 Key4.exe（Windows）](https://github.com/vvangpc/kay4/releases/download/v1.0.0/Key4.exe)**

Key4 用于给兼容的 USB 四键小键盘（VID `413D` / PID `553A`）设置快捷键和宏。下载后双击运行，无需安装 Python。配置写入键盘后，关闭 Key4 也能使用。

## 快速上手

1. 插上小键盘，打开 `Key4.exe`，等界面显示「已连接」。
2. 在左侧选择要设置的按键。在「快捷键」页输入或录入组合键，也可以在「宏」页录制一串按键并调整延时。
3. 点击「写入按键 N」保存当前键，或点击「写入全部」保存已设置的键。写入后按一下实体键，确认动作正确。

需要确认实体键对应哪个格子时，先写入完整的四键配置，再开启「按键定位」。按下实体键即可选中对应格子。定位期间会暂时停用原按键动作，关闭定位后会恢复。

更多操作与异常恢复方法见[使用说明](使用说明.txt)。
